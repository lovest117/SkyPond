# 半亩方塘 v1.2.0

半亩方塘的第一个「四时」版本：池塘开始跟着你所在的时间和地方走。

## 此刻此地（四时面板顶部）

- 「自动获取」一开，四季、昼夜、月相、天象都按**当下时间与地点**自己决定，手动选项整体收起；点「手动接管」随时解耦，原来的值原样保留。
- 四季按**四立节气**换：立春 2/4 春 · 新荷、立夏 5/5 夏 · 盛荷、立秋 8/7 秋 · 残荷、立冬 11/7 冬 · 枯荷。
- 昼夜按所选城市的**日出日落**分晨曦 / 晌午 / 斜阳 / 暮色，入夜在日落 20 分钟后；时间按城市所在时区算，不是设备时区。
- 夜里的月相按**天文月龄**取新月 / 弦月 / 满月（自动档不会给「星夜」）。
- 定位尽力而为：拒绝或超时就提示先填城市，不会硬开；手填城市走 Open-Meteo 地理编码，选中即接上。已经有城市时表单收起，只留「换城市」。
- 断网或天气服务失败时保留上一次的四时与快照，超过 20 分钟会在面板注明「沿用 HH:MM 的快照」。
- 每分钟校一次此刻，只有季节、昼夜、时段或月相真的变了才重绘；换季先压暗 340ms 再换底图，回升时新图已经在了。

## 四时面板（底栏第三项）

- 四季 / 昼 / 夜各四项：昼是晨曦 · 晌午 · 斜阳 · 暮色（改冷暖、亮度、太阳方向、焦散强弱与影子软硬），夜是新月 · 弦月 · 满月 · 星夜。
- 「昼」与「夜」改成并排分段控件：选昼只出白昼四时段，选夜只出夜晚四相，切回来还记得上次选的时段。
- 星夜：没有月亮，池中不再映出月盘与月晕，只剩星光与水面碎影。只在手动档可选。
- 夜里鱼游得更慢（约平时的 55%）、更常停着歇息，画面自动走节能档（30 帧、1 倍像素密度），更省电也更省内存。
- 换季时底图与画面交叉淡入，不再硬切。

## 养成与画鱼

- 鱼苗养成：新鱼以苗期入水（成年体长的 62%），连续喂满 7 个不同日子才成年，列表里显示「苗期 · 已喂 N/7 天」。
- 岸边排队：池塘满 60 尾后放入的新鱼先排队（最多 20 尾），放生一尾就自动游进来，一次不丢。
- 画鱼闭环：打开「我的锦鲤」就能在预览鱼身上按住拖动直接画，起名后按「画好了，放入池塘 ＋」一次完成，面板自动关闭。
- 食量榜并入「我的锦鲤」面板末尾，省掉一个底栏入口。

## 分发与平台

- Windows 包内附 `0-点我启动.bat` 与包内 `README.txt`（三步装好、用法、卸载与数据位置），不做安全提示绕过。
- Android 原生壳沿用包名 `com.skypond.koipond`、应用名「半亩方塘」与同一把签名密钥，可直接覆盖安装，池塘里的鱼和设置都会保留。
- 三个平台的包都由 GitHub Actions 在 tag 上构建并附 `SHA256SUMS.txt`。
