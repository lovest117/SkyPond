# 半亩方塘 v1.2.1

天象的四个名字短了一截，昼与夜之间也不再是“啪”地一下换过去。

## 顶部一条

- 原来在右上角的天气卡移到屏幕正上方，并排显示真实时间、日期与农历、昼夜图标（跟随城市时附带温度）与四时设置按钮；窄屏下自动折成两行。
- 去掉了「晴空 / 随心天气」这类重复文案：图标只表示昼与夜，天象文字交给下面的小签。
- 城市右侧固定一句跟天象、昼夜对应的诗，只留单句、连标点不超过 10 字：晴「水光潋滟晴方好」、云「闲云潭影日悠悠」、雨「细雨鱼儿出」、雪「晚来天欲雪」；夜里「明月松间照」、星夜「满船清梦压星河」、云夜「云破月来花弄影」、雨夜「夜雨敲荷，一池清响」、雪夜「雪落无声」。
- 天气卡下方新增一枚小签，显示池塘**此刻模拟**的四时：季节 · 昼夜 / 月相 · 天象（例如「春 · 新荷 · 昼 · 斜阳 · 下雨」），不含真实日期时间；点它直接打开四时面板。

## 天象改名

- 四时面板的四个按钮由「晴日 / 多云 / 下雨 / 落雪」改成单字「晴 / 云 / 雨 / 雪」，在窄屏上更好按。
- 其它地方仍写全：右上角天气卡「晴空」，此刻此地摘要「冬 · 昼 · 斜阳 · 晴空」。
- Wallpaper Engine 的 `weather` 选项标签同步改为 晴 / 云 / 雨 / 雪（值仍是 `sunny` 等，老配置不会被清掉）。

## 昼夜平滑过渡

- 点「昼 · 四时 / 夜 · 四相」、换白昼时段、换月相，池塘的天光改为约 4–5 秒缓慢过渡：日头一点点落下去、池水由暖转青、月亮在水面慢慢显出来，不再是瞬间跳变。
- 天气切换、季节切换、雨雪量调整仍保持原来的短过渡，不拖慢手感。
- 夜晚照旧自动放慢鱼、走节能画质。

## 其它

- 「风起」滑杆不再提供：风回到固定的微风档，不再随城市实时风速变化；雨丝、雪花、云影、荷叶的默认手感与 v1.2.0 一致。
