# 半亩方塘 v1.2.2

这一版是 Windows 桌面版的可靠性修复，外加一个能让你把问题直接“寄回来”的诊断入口。

## 桌面壁纸挂载更可靠

- 以前如果壁纸窗口没能挂进资源管理器的桌面层，它也照样显示，结果就是一个没有边框的全屏窗口盖住桌面和图标；按“显示桌面”又能看到原来的壁纸。现在挂载后会核对父窗口，挂不上就**不显示**，只留托盘图标并弹提示，不会再出现这种情况。
- 桌面层探测更严格：只接受**可见、盖住整个虚拟屏幕**的 `WorkerW`，并排除机器上常见的 136×38 隐藏工具窗口；一次没分出来会重试三次（约 1 秒），避免资源管理器刚启动时的竞态。
- 以**管理员权限**运行时直接提示并退出：Windows 不允许把窗口挂进普通权限的资源管理器桌面层，这正是“空白窗口盖住桌面”的常见原因。
- 缺少 `web\` 子目录时给出明确提示，并打开程序文件夹；不会再只显示一片空白。

## 诊断日志与一键上传

- 每次启动都会把系统版本、是否管理员、WebView2 版本、屏幕、`Progman / WorkerW` 层级和挂载结果写进 `%LOCALAPPDATA%\SkyPond\error.log`。挂载失败时额外记录错误与父窗口句柄。
- 托盘菜单新增「诊断日志…」：可以复制全文、打开日志文件夹，或**一键上传**到匿名粘贴服务（dpaste，保留 30 天，无需账号）并自动把链接复制到剪贴板。
- 日志在写入时就去掉了用户名、电脑名和用户目录，只保留排障需要的系统与窗口信息。

## 顺带

- 带上一个 1.2.1 的小补丁：顶部时钟改为分钟级刷新，数字变化时有一个轻翻的过渡，不再每秒重绘。
- Android 与 Web 版的界面和功能与 1.2.1 一致，没有变化。
