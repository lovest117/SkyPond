# 半亩方塘 v1.2.3

这一版是给 Web 首访“减负”的小版本，外加两处安全与说明上的补丁；画面和交互没有变化。

## Web 首访少下一次底图

- 以前无论从网页打开、还是 Windows 桌面版启动，都会先加载 `assets/pond-data.js`（431 KB 的内嵌底图）。经 Brotli 压缩后仍有 323 KB，和原图几乎一样大，等于每次首访都多付一张图的流量。
- 现在只有 **直接双击 `index.html`（`file://`）** 时才加载它——那种打开方式下，外部图片会污染画布和 WebGL 纹理，必须用内嵌底图兜底。
- 网页与 Windows 桌面版走 `https`，改读 `assets/pond.webp` 与四季图，不再请求这份内嵌数据；Windows 运行时也不再解析它。安装包内仍保留该文件，所以**包体大小不变**，省下的是启动时的解析和网页的首次下载。
- 直接双击 `index.html` 的离线打开方式保持原样，默认底图照常显示。

## 城市名按纯文本处理

- 「此刻此地」卡片里的城市名与摘要，原先直接拼进 HTML。现在统一转义后再显示：即使城市名里带 `<`、`>`、引号之类的字符，也只会原样显示为文字，不会被当成标签执行。
- 常规城市名（北京、杭州、Shanghai 等）显示效果完全不变。

## 说明文件补上隐私口径

- `README.md` 与 Windows 包内的 `README.txt` 新增一段：只有开启「此刻此地」或手动查询城市时，才会把城市名（地理编码）或城市坐标（天气与日出日落）发给 Open-Meteo；不发送设备标识、不做统计、不上传池塘内容；断网时只少了实时天气，其余功能照常。

## 其他

- Android 与 Windows 的界面、功能和上一版一致。
- 新功能（节气、锦鲤纪念日、投喂统计等）留到 1.3.0 再谈，这一版不夹带。
