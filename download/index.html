把池塘带回去

三个平台共用同一套池塘。Windows 版铺在桌面图标之下，Android 版作为动态壁纸，浏览器版打开就能看。

Windows 10 / 11

解压整个文件夹，直接双击 SkyPond.exe；不要只把 exe 单独拿出来。首次运行可能提示“已保护你的电脑”，点“更多信息 → 仍要运行”。

前往 Release 下载

需要 Microsoft Edge WebView2 运行时（Windows 11 自带）。必须以普通权限运行，不要用“以管理员身份运行”。

Android 7.0+

下载 APK 传到手机安装，允许「安装未知来源应用」，再在系统壁纸里选择半亩方塘。

前往 Release 下载

浏览器 / 手机网页

不用下载，打开就能看。支持“添加到主屏幕”，第二次打开断网也能显示池塘。

扫码打开

手机扫码直接进入网页版；也可以在浏览器里“添加到主屏幕”，像一个小应用一样打开。

校验与版本

每个 Release 都附带 SHA256SUMS.txt，下载后可以核对文件是否完整。当前版本 1.2.3。
