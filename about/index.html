A LITTLE POND, A QUIET MIND

一方池塘，片刻闲心

半亩方塘是一个可以投喂锦鲤、听雨观鱼的动态池塘。它铺在桌面图标之下，或安静地待在浏览器里；四季、昼夜、月相和天气都在其中慢慢流转。

可以做什么

  • 在桌面或水面轻点投喂，锦鲤游过来抢食；也可以静静观鱼，看它们受惊散开。
  • 切换四季与白昼四时（晨曦 / 晌午 / 斜阳 / 暮色），夜里还有新月、弦月、满月与星夜。
  • 让「此刻此地」按当下时间与城市自动定四季、昼夜、月相和天气；断网时退回手动，不影响其他功能。
  • 听溪流、山泉、雨声、古琴或颂钵；所有声音由 Web Audio 实时合成，没有音频文件。
  • 给锦鲤起名、看食量榜、在沉浸模式里藏起所有界面。

怎么用

Windows 桌面

解压整个文件夹，直接双击 SkyPond.exe。池塘位于桌面图标之下，不挡正常使用。

它不是什么

没有账号、没有云同步、没有排行榜和社交，也没有广告与推送。它是一方自己的池塘，不是需要每天打开的任务。
